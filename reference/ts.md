# ts

ts modified from pharmaversesdtm

## Usage

``` r
ts
```

## Format

A data frame with 33 rows and 6 variables:

- STUDYID:

  Study Identifier

- DOMAIN:

  Domain Abbreviation

- TSSEQ:

  Sequence Number

- TSPARMCD:

  Trial Summary Parameter Short Name

- TSPARM:

  Trial Summary Parameter

- TSVAL:

  Parameter Value

## Source

data from pharmaversesdtm.

# ie

ie modified from pharmaversesdtm

## Usage

``` r
ie
```

## Format

A data frame with 60 rows and 4 variables:

- STUDYID:

  Study Identifier

- USUBJID:

  Unique Subject Identifier

- IECAT:

  IE Category

- IETEST:

  IE Criterion Test Name

## Source

data from pharmaversesdtm.

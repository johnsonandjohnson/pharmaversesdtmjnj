# ie

ie modified from pharmaversesdtm

## Usage

``` r
ie
```

## Format

A data frame with 60 rows and 12 variables:

- STUDYID:

  Study Identifier

- USUBJID:

  Unique Subject Identifier

- VISIT:

  Visit Name

- VISITNUM:

  Visit Number

- DOMAIN:

  Domain Abbreviation

- IESEQ:

  Sequence Number

- IECAT:

  Inclusion/Exclusion Category

- IETEST:

  Inclusion/Exclusion Criterion Test Name

- IETESTCD:

  Inclusion/Exclusion Criterion Short Name

- IEORRES:

  Result or Finding in Original Units

- IESTRESC:

  Character Result/Finding in Standard Format

- IEDTC:

  Date/Time of Collection

## Source

data from pharmaversesdtm.

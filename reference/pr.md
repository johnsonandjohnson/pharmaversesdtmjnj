# pr

pr created from scratch

## Usage

``` r
pr
```

## Format

A data frame with 80 rows and 11 variables:

- STUDYID:

  STUDYID

- DOMAIN:

  DOMAIN

- USUBJID:

  USUBJID

- PRSEQ:

  Sequence Number

- PRTRT:

  Therapeutic or Diagnostic Procedure

- PRDECOD:

  Standardized Procedure Name

- PRINDC:

  Indication

- PREVINTX:

  Prior Intervention

- PRSTDTC:

  Start Date/Time of Procedure

- PRENDTC:

  End Date/Time of Procedure

- PRDUR:

  Duration of Procedure

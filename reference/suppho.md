# suppho

suppho created from scratch

## Usage

``` r
suppho
```

## Format

A data frame with 5955 rows and 8 variables:

- STUDYID:

  Study Identifier

- RDOMAIN:

  Related Domain

- USUBJID:

  Unique Subject Identifier

- IDVAR:

  Identifying Variable

- IDVARVAL:

  Identifying Variable Value

- QNAM:

  Qualifier Variable Name

- QLABEL:

  Qualifier Variable Label

- QVAL:

  Qualifier Value

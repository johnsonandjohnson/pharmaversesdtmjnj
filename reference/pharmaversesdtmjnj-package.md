# pharmaversesdtmjnj: J&J Innovative Medicine SDTM Test Data

A set of Study Data Tabulation Model (SDTM) datasets constructed by
modifying the 'pharmaversesdtm' package to meet J&J Innovative
Medicine's standard data structure for Clinical and Statistical
Programming.

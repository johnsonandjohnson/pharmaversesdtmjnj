# supppr

supppr created from scratch

## Usage

``` r
supppr
```

## Format

A data frame with 240 rows and 8 variables:

- STUDYID:

  Study Identifier

- RDOMAIN:

  Related Domain Abbreviation

- USUBJID:

  Unique Subject Identifier

- IDVAR:

  Identifying Variable

- IDVARVAL:

  Identifying Variable Value

- QNAM:

  Qualifier Variable Name

- QLABEL:

  Qualifier Variable Label

- QVAL:

  Qualifier Value

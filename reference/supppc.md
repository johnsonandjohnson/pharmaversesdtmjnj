# supppc

supppc modified from pharmaversesdtm

## Usage

``` r
supppc
```

## Format

A data frame with 4572 rows and 8 variables:

- STUDYID:

  Study Identifier

- RDOMAIN:

  Related Domain Abbreviation

- USUBJID:

  Unique Subject Identifier

- IDVAR:

  Identifying Variable

- IDVARVAL:

  Identifying Variable Value

- QNAM:

  Qualifier Variable Name

- QLABEL:

  Qualifier Variable Label

- QVAL:

  Qualifier Value

## Source

data from pharmaversesdtm.
